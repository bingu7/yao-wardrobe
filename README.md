# 私人衣橱小程序

一个原生微信小程序，用于在本机管理衣物、穿搭、穿着记录和购买愿望。项目不依赖服务器、云函数或账号体系，业务数据与用户图片默认保存在当前设备的微信小程序存储中。

## 功能概览

### 衣橱管理

- 新增、编辑、查看和删除衣物
- 保存衣物原图、价格、颜色、季节、场合、购买日期、状态和备注
- 按名称、分类、颜色、备注或场合搜索
- 分类筛选、展开收起和自定义排序
- 批量修改分类、追加场合或删除衣物
- 图片加载失败时自动清理失效的本地路径

### 穿着记录与统计

- 按日期记录当天穿过的衣物
- 自动维护穿着次数和最近穿着日期
- 查看穿着日历、久未穿着提醒和本周推荐
- 计算单次穿着成本
- 汇总总件数、总花费、平均价格、闲置数量、分类、季节和场合分布
- 查看最常穿、最久未穿和最高单次穿着成本的衣物

### 穿搭组合

- 每套穿搭可自由选择最多 5 件现有衣物
- 新增、复制、编辑和删除穿搭
- 按场合筛选穿搭
- 分类选择只显示衣橱中实际存在衣物的分类
- 衣物删除或分类变化时自动修正穿搭引用

### 愿望清单

- 记录想购买的衣物、预计价格、图片和备注
- 新增、编辑、搜索和分类筛选愿望
- 将愿望标记为已购买并加入衣橱
- 愿望图片可随完整备份一起恢复

### 本地备份与恢复

- 生成包含衣物、穿搭、愿望、穿着记录和图片内容的完整 JSON 备份
- 支持复制备份内容、分享备份文件或在兼容的桌面微信中保存到电脑
- 支持选择 JSON 文件或粘贴内容恢复
- 恢复时把图片重新写入当前设备并替换为有效的本地路径
- 兼容旧版不含图片内容的备份
- 可将全部衣物和愿望原图逐张保存到手机系统相册

## 数据存储说明

结构化数据通过 `wx.setStorageSync` 保存在微信本地缓存中，图片保存在小程序持久文件目录或 `wx.env.USER_DATA_PATH` 中。上传代码、提交 Git 或发布新版本都不会把开发者工具里的衣物和图片上传给其他用户。

以下操作可能导致本地数据丢失：

- 更换手机
- 清理微信缓存
- 卸载小程序
- 手动清空本地数据

建议定期在“统计 → 设置与关于”中生成完整备份。完整备份可能包含个人图片、价格和备注，请妥善保存，不要公开提交到仓库。

## 如何运行

1. 克隆仓库并打开微信开发者工具。
2. 选择“导入项目”，项目目录指向仓库根目录。
3. 使用自己的 AppID、测试号或开发者工具支持的测试模式。
4. 选择兼容的基础库版本并点击“编译”。

`project.config.json` 和 `project.private.config.json` 属于本机配置，不由 Git 跟踪。首次导入时可由微信开发者工具创建或维护。

## 自动测试

项目测试使用 Node.js 内置的 `assert`，不需要安装 npm 依赖：

```bash
node tests/wardrobe.test.js
```

测试覆盖数据增删改、级联引用、穿着记录、批量操作、普通备份、图片备份恢复和关键页面表单逻辑。

## 当前架构边界

- 没有服务端账号和跨设备自动同步
- 备份恢复采用按 ID 与更新时间合并的策略，不是云端实时同步
- 本地存储容量、文件生命周期和系统相册权限由微信运行时决定
- 如需多人使用或自动跨设备同步，需要另行接入云数据库、云存储和用户身份体系
