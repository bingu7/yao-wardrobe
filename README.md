# 私人衣橱小程序

这是一个原生微信小程序 MVP，用来管理自己的裙子、衣服、鞋包和配饰。

## 已实现功能

- 衣物列表
- 分类筛选
- 名字搜索
- 新增衣物
- 上传衣物图片
- 编辑衣物
- 删除衣物并二次确认
- 查看衣物详情
- 统计总件数、总花费、平均单价、闲置数量和分类数量
- 场合标签：通勤、约会、旅行、拍照、正式、休闲、运动
- 自定义分类：添加衣物和愿望清单时可以输入新种类
- 穿着记录：详情页点击“今天穿了”记录穿着次数和最近穿着日期
- 单次穿着成本：按 `价格 / 穿着次数` 自动计算
- 穿搭组合：保存“上衣 + 裙子/裤子 + 鞋子 + 包包 + 帽子/发饰”
- 愿望清单：记录想买的衣物、预计价格、参考图和想搭配的已有衣物

## 数据字段

每件衣物包含：

- 图片
- 名字
- 种类
- 价格
- 颜色
- 季节
- 场合标签
- 购买时间
- 状态
- 穿着次数
- 最近穿着日期
- 单次穿着成本
- 备注

## 如何运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`private-wardrobe-miniprogram`。
4. AppID 可以先选择测试号或使用游客模式。
5. 点击编译预览。

## 当前存储方式

当前版本使用 `wx.setStorageSync` 保存在本地缓存里，适合原型和个人练习。

详情页进入编辑时会把当前衣物 ID 临时写入本地缓存，再切到“添加”Tab 复用同一个表单页面，这是为了避开微信小程序 Tab 页面不能带参数 `navigateTo` 的限制。

后续如果要长期使用，建议接入微信云开发：

- 衣物数据保存到云数据库
- 衣物图片保存到云存储
- 用用户 openid 区分不同用户的数据
